# Release checklist

## Required

- [ ] Vercel dependency installation completes without peer-dependency resolution stalls.
- [ ] `npm run release:check` passes.
- [ ] Production build completes.
- [ ] Homepage, artist pages, and information pages load.
- [ ] Splash appears once per tab session.
- [ ] Mobile menu opens, scrolls, closes, and restores focus.
- [ ] Safari loading chrome remains light/transparent as approved.

## Before enabling indexing

- [ ] Replace `.example` contact addresses.
- [ ] Confirm organizer details.
- [ ] Confirm final venue and event information.
- [ ] Configure ticket and newsletter URLs when ready.
- [ ] Set the final site URL and enable indexing explicitly.
