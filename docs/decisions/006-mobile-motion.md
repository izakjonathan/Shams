# 006 — Progressive mobile motion

Keep browser-native CSS motion and IntersectionObserver; do not add a motion framework or scroll listeners. Start with readable server HTML, arm only off-screen content, and reveal once. Keep programme controls stationary and handle keyboard focus and live reduced-motion preference changes.

Scope translation to small elements and full-screen mounted overlays. Use shorter mobile durations, capped arrival staggers and transform/opacity effects. Preserve the FAQ grid disclosure because it needs natural document flow. Bound the splash asset/font waits, keep gallery image layers to a three-slide window and suspend playback outside the visible page.

See ../MOTION_REVIEW.md for evidence, exact timings, tradeoffs and device-verification limits.
