# Component standard

Every new Studio UI component should include:

1. A typed React API.
2. A registry entry with source, status, maturity and dependencies.
3. Keyboard-accessible interaction and visible focus.
4. Responsive behavior at mobile, tablet and desktop widths.
5. Dark and light theme compatibility.
6. Copyable usage documentation.
7. No unnecessary runtime dependency.
